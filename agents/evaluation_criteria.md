# 평가 기준표 (멀티파일 Next.js 프로젝트용)

Generator와 Evaluator가 공유하는 품질 기준.

---

## 채점 항목

### 1. 디자인 품질 (비중: 30%)
색상, 글꼴, 레이아웃이 하나의 분위기를 만드는가?

합격: 일관된 다크 모던 팔레트, 글꼴 통일, 여백 규칙 일정, "프리미엄 뉴스 플랫폼"으로 느껴짐
불합격: 색상 산만, 다크/라이트 혼재, AI slop 패턴 (보라색 그라데이션 + 흰색 카드)

### 2. 독창성 (비중: 20%)
이 프로젝트만의 개성이 느껴지는가?

합격: Bloomberg/Reuters 스타일이면서 차별화된 요소 있음, 타이포/레이아웃에서 예상 밖 선택
불합격: Bootstrap 기본 느낌, 뻔한 뉴스 사이트, 기억에 남는 요소 없음

### 3. 기술적 완성도 (비중: 25%)
코드 품질과 안정성이 갖춰져 있는가?

합격: TypeScript 오류 없음, 반응형 정상, 코드 중복 제거, 디자인 토큰 일관 적용, 임포트 경로 정확
불합격: 빌드 실패, 타입 에러, 중복 코드 잔존, 하드코딩 값 사용

### 4. 기능성 (비중: 15%)
직관적으로 사용할 수 있는가?

합격: 네비게이션 명확, 검색 정상, 카테고리/국가 필터 동작, 기사 상세 정상 표시
불합격: 링크 깨짐, 버튼 동작 안 함, 정보 순서 혼란

### 5. 회귀 안전 (비중: 10%)
기존 기능이 보존되었는가?

합격: 582개 기사 정상 표시, 검색/필터/페이지네이션 동작, API 엔드포인트 호환, DB 무결
불합격: 기존 페이지 깨짐, API 변경으로 프론트엔드 오류, 데이터 누락

---

## 판정

가중 점수 = (디자인×0.3) + (독창성×0.2) + (기술×0.25) + (기능×0.15) + (회귀×0.1)

- 7.0 이상 → 합격
- 5.0~6.9 → 조건부 합격 (피드백 반영 후 재검수)
- 5.0 미만 → 불합격
- 디자인 또는 기술적 완성도 4점 이하 → 무조건 불합격

---
